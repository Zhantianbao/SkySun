# SkySun v1.7.0 — Hosted Knowledge Embeddings

## Changes

- Document ingestion and knowledge search use Alibaba Cloud Model Studio's `qwen3.7-text-embedding` through its OpenAI-compatible synchronous API. DeepSeek continues to handle chat and reasoning.
- Knowledge vectors use 1,024 dimensions. New databases create the matching pgvector column; empty tables from the previous local model are adjusted automatically.
- The backend image no longer installs PyTorch or downloads the local E5 model. Configure `DASHSCOPE_API_KEY` and a region-matched `DASHSCOPE_BASE_URL` before starting the application.
- Frontend test dependencies include a patched Vitest release, with no findings in the current npm audit.

## Upgrade notes

The default Beijing workspace can use `https://dashscope.aliyuncs.com/compatible-mode/v1` without a workspace ID. A populated database containing old 384-dimensional knowledge vectors requires a separate data migration before this version can start. SkySun stops with an explicit error instead of mixing vectors from different models.

## Verification

The backend suite passed 110 tests. The frontend suite passed 13 tests, the production frontend build succeeded, and npm audit reported no findings. The Python wheel built successfully. The Model Studio endpoint returned valid 1,024-dimensional query and document vectors in a live smoke test. Docker Compose startup was not run locally; the repository's Docker Compose workflow can be triggered manually in GitHub Actions or through a pull request before publishing.
