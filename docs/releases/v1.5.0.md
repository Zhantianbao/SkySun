# SkySun v1.5.0 — Desktop Companion Foundation

## Features

- Register personal computers under a SkySun user account with a separate device credential.
- A foreground Python companion reconnects over WebSocket and reports hostname, OS, CPU, memory, disk usage, and heartbeat time.
- An owner-scoped `/devices` dashboard shows current and offline devices on desktop and mobile.

## Architecture and security

FastAPI stores device registrations and latest status in PostgreSQL. The device token is returned at registration, stored as a hash on the server, and used only for its WebSocket connection. Nginx forwards `/api/ws/` to FastAPI. Online status requires both an active session and a recent heartbeat; a stale connection is shown offline. The companion has no remote command execution and only permits plaintext HTTP for loopback development.

## Verification

Backend tests, desktop companion tests, frontend tests/build, dependency check, and Docker Compose startup verification are required for this release.

## Limitations

The companion must run in the foreground. It reports computer resources, not active projects, editor state, screenshots, or reminders. These capabilities are planned for v1.6.0.
