# SkySun v1.6.0 — Remote Development Assistant

## Features

- The desktop companion reports the user-selected project, Git branch, changed-file count, recent activity, VS Code presence, and user-confirmed Codex activity.
- An optional local VS Code extension reports the opened workspace. The companion accepts it only when it matches the selected project and the report is fresh.
- An authenticated owner can request one screenshot at a time, view it on `/screenshots`, and send short reminders to the companion's local inbox.

## Architecture and security

The existing device WebSocket carries allowlisted heartbeat fields and pending screenshot or note requests. The server stores owner-scoped requests, screenshot bytes, notes, and audit events in PostgreSQL. Screenshots are captured only after an owner request, sent with the separate device credential, capped at 5 MiB, and removed after 24 hours. Requests expire after two minutes. The companion runs only fixed Git read-only commands inside the locally selected workspace. It does not expose remote shell or Codex control.

## Verification

Backend API and PostgreSQL tests, WebSocket and desktop companion tests, frontend tests/build, dependency checks, and Docker Compose startup and request-flow verification are required for release.

## Limitations

The companion must run on the user's computer with screenshot permission. Headless Linux sessions may reject screen capture. Codex activity is explicitly confirmed by the user for two hours; it is not inferred from Codex internals. VS Code workspace discovery requires the optional local extension. There is no arbitrary remote execution or continuous recording.
